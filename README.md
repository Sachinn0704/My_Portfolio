# Sachin B — Data Science & AI Portfolio

A personal portfolio web application built with React and TypeScript. It presents professional information, technical skills, projects, and data-oriented work through a modern frontend interface.

## Project Summary

This repository contains a Vite-powered React application. The project uses React, TypeScript, Recharts, Lucide React, and Google's Generative AI SDK as application dependencies.

## Technology Stack

- React 19
- TypeScript
- Vite
- Recharts for data visualization
- Lucide React for interface icons
- Google GenAI SDK for AI-enabled functionality

## Main Purpose

The portfolio is intended to provide a single place to present:

- Technical skills
- Data science and AI projects
- Software development experience
- Professional profile information
- Project highlights and visual content

## How to Run Locally

### 1. Install Node.js

Install Node.js and npm.

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

If an AI-enabled feature is used, create `.env.local` and provide the required Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

Never commit API keys to the repository.

### 4. Start development server

```bash
npm run dev
```

### 5. Build the application

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```
